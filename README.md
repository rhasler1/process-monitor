Some notes:

- Working on components/
    - Experimenting with MVC
    - Components are dependant on a domain model
    - Domain model's are immutable
    - Controller's modify a Component's state
    - A view is generated by providing the omponent's state and the
    domain model it is dependant on
    - Component's do not store references to the domain model
    - The App provides a reference to the component on most (if not all)
    calls to the component.
    - Component state enforces invariants of the domain model
